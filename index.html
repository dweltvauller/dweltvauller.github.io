V.O.C.K.

Vocal Output Creation Kit

Fallout 2 Voice Modding Pipeline

V.O.C.K. is a Python tool that automates the complete voice-modding pipeline for Fallout 2. Feed it a mod's dialogue (.msg) files and a folder of raw audio, and it produces a ready-to-install .dat archive containing normalized ACM audio, lip-sync data, and the dialogue files themselves — the same format the original game uses.

It exists to make full voice acting for Fallout 2 total conversions and restoration projects practical: instead of hand-building lip files and audio archives per NPC, one config and one command line produce the whole mod.

Pipeline

msg ────────[parse per-language encoding]─► txt (one per dialogue line) ↕ optional: edit manually here audio ──────[ffmpeg normalize + encode]───► wav (22050 Hz mono 16-bit) wav ────────[snd2acm / wine]──────────────► acm wav + txt ──[MFA forced alignment]────────► textgrid textgrid ───────────────────────────────────► lip msg + acm + lip + txt + scripts ────────────► dat/vock.dat
